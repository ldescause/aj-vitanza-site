Drop merch photography here.

Filenames referenced by merch.js (change them there if you prefer other names):
  tee-front.jpg      tee-back.jpg
  hoodie-front.jpg   hoodie-back.jpg
  poster.jpg

Specs:
  - Square (1:1). 1200x1200 is plenty.
  - JPG for photos, ~200-400KB each. Compress before committing.
  - Shoot or crop on a dark background so cards blend with the site.
  - The "-back" image is optional; it cross-fades in on hover.
  - If a file is missing, the card falls back to a dashed
    "Artwork coming" placeholder — nothing breaks.
